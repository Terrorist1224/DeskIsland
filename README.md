# 桌屿 DeskIsland

桌屿是一款 Windows 桌面磁贴应用，将音乐播放信息、歌词、天气、待办、倒计时和多媒体控制放在桌面上。当前版本：**1.3.0**。

## 功能

- 音乐磁贴：封面、播放状态、歌词，以及播放器支持的播放控制；提供方形和横向款式。
- 天气磁贴：添加多个地区，选择城市或区县；支持地区、省市区信息展示和独立显示开关。
- 待办磁贴：五种低饱和事项底色、浅黄日期与时间选择面板、完成确认、纵向拖拽排序、精确到秒的全屏提醒与提醒预览。
- 多媒体磁贴：滚轮实时调节系统音量、默认输入／输出设备切换，以及系统声音＋默认通信麦克风的双音源 MP3 录音。
- 倒计时磁贴：时分秒滚轮、本地预设、剩余进度圆环、暂停与继续；到期在磁贴内提示并临时置顶，点击勾确认后恢复桌面层级；最小尺寸 160×160，文字与按钮已放大，标题与天气地区文字大小一致。
- 桌面编辑：拖动、缩放、网格对齐，保存磁贴布局；待办可分别拉伸宽度和高度，音乐与天气沿用等比缩放。
- 托盘运行：关闭主控窗口后继续显示磁贴，从托盘打开主控或退出。
- 开机自启：登录当前 Windows 账号时恢复磁贴和托盘。

## 系统要求

- Windows 10 / Windows 11，x64。Windows 桌面行为需要在目标系统上验证，不支持 macOS、Linux 或原生 ARM64 包。
- 当前音乐磁贴仅支持 QQ 音乐的 Windows 系统媒体会话；不支持网易云音乐或浏览器媒体控制。QQ 音乐不支持的进度操作不会开放。
- 天气和在线歌词需要网络连接。
- 安装目录须允许当前账号写入，运行时无需管理员权限。

## 安装与启动

1.3.0 Windows x64 安装包为 `DeskIsland-1.3.0-Setup.exe`，按向导安装。安装包和对应的 `.sha256` 校验文件位于项目 `dist/`，也通过 GitHub「发布1.3.0」发行版提供下载。首次安装、覆盖升级及卸载仍需在目标电脑验收。

默认路径为 `C:\DeskIsland`。选择 `D:\` 或 `D:\软件` 时，最终路径分别为 `D:\DeskIsland`、`D:\软件\DeskIsland`；已有末级 `DeskIsland` 时不会重复追加。目录不可写时，请选择另一个可写路径。

安装会创建开始菜单和桌面快捷方式。首次安装不包含开发者的个人数据，开机自启默认关闭。

## 使用

1. 在左侧打开音乐磁贴，按需选择款式。
2. 添加天气磁贴并选择地区，再启用对应磁贴。
3. 点击「编辑桌面」调整位置与大小；点击「完成编辑」或按 Esc 锁定布局。
4. 点击窗口右上角关闭按钮收起到托盘；从托盘菜单选择「退出」结束程序。

主控中的歌曲和天气预览标有示例信息，不代表真实播放状态或实时天气。

### 多媒体

- 在左侧开启「多媒体」，默认及最小尺寸为 240×192，沿用音乐、天气的圆角深色透明背景，支持等比放大。旧方形或 240×160 音频磁贴加载时转换为新比例，保留位置、标识和设置。
- 「音量」、音量条和百分比在同一行，所有文字统一为当前紧凑天气地名的 14px 和相同字体；移除底部常驻音源说明。音量条仅接受鼠标滚轮，每次向上／下调整 2 格，滚动时立即提交系统音量；点击、拖动和方向键不改变音量。音频窗口不启用后台绘制节流，旧音量回执不能回退较新的显示；Windows 中的音量变化会同步显示。
- 磁贴顶部显示「多媒体」，主程序目录、页面标题及开关名称同步使用该名称；新增标题后高度为 192px。
- 录音完成后恢复圆形麦克风，不显示保存成功文案或打开文件夹按钮；错误与重试入口仍可见。麦克风及录音波纹按钮在输入设备行以下的剩余区域垂直居中。
- 输出选择当前系统默认输出，输入显示默认通信麦克风。选择设备会同步修改该方向的普通默认与通信默认；不会覆盖软件自己指定的设备。列表在磁贴内使用圆角、半透明深色面板和平滑展开／收拢动画，支持方向键和 Esc；点击其他位置或窗口失焦时收拢，选择后立即收拢并更新名称，切换失败则恢复实际设备并显示错误。
- 点击圆形麦克风按钮，同时采集默认输出设备的系统声音及默认通信麦克风，混合为双声道 48kHz、192kbps MP3。录音期间按钮显示实际混合 PCM 驱动的声音波纹和停止图标，点击停止进入保存流程。不提供暂停，不开启麦克风监听。
- 录音期间设备选择不可用；相关默认设备变化、录音设备断开或磁贴开关关闭会停止录音，并保留已录内容进入保存流程。关闭主控窗口不影响录音。
- 停止后选择保存位置；取消保存对话框时自动存到系统桌面。文件名为 `录音 YYYY年MM月DD日 HH时mm分ss秒.mp3`，使用录音开始时间和上海时区，同名文件增加数字后缀。
- 正常退出程序时停止录音并自动保存到桌面。编码或写入失败会保留临时录音，可从磁贴或主控音频页重试；异常退出后的未完成录音在下次启动时尝试恢复到桌面，不自动开始新的录音。
- 临时音频与恢复信息位于应用数据目录的 `recordings/`（正式版为安装目录的 `data/recordings/`）。成功保存后清理对应临时数据，长录音会占用磁盘空间。
- 需要 Windows 麦克风权限和可用的音频设备。1.3.0 安装包已包含 NAudio 与 FFmpeg 运行时，无需另行安装编码器。第三方组件及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

### 待办

- 在左侧启用「待办」。默认是圆角正方形，底部显示「待办」和添加按钮；内容超出时可在磁贴内滚轮滚动，不显示滚动条。
- 点击右下角「＋」输入内容，色盘可选择浅黄、浅绿、浅蓝、浅橙或浅粉。按回车或点击「创建」保存；输入法选词时的回车不会直接创建。
- 闹钟按钮可开启或取消提醒，使用本机日期和 24 小时制的时、分、秒选择器。提醒时间必须在未来，也可以创建不带提醒的事项。
- 点击日期字段，在原编辑区域内展开日历；左右箭头切换月份，点击日期后收起。点击时、分或秒字段展开三列时间列表，选择后点击「确定」收起；日期与时间面板不会同时展开，也不会打开新窗口。
- 日期与时间选择区域统一使用预设浅黄，事项本身仍可选择五种颜色。时间列表支持方向键调整、Home/End 跳到首尾；焦点在选择区域内时，Esc 只收起面板并保留草稿。较小磁贴可滚动编辑区域查看展开内容。
- 点击事项时，原文字替换为同字号的「完成待办」，底部「待办」替换为浅绿色「是」和浅红色「否」。点击「是」删除该事项，「否」、点击其他位置、窗口失焦或 Esc 取消确认。切换到另一事项时按钮持续保留，被遮挡的确认行会平滑滚动到完整可见位置。
- 按住鼠标左键上下拖拽事项可调整顺序，只有纵向移动；其他事项平滑让位，松手后保存顺序。拖到列表边缘会自动滚动；失焦或 Esc 取消尚未松手的拖拽。
- 编辑桌面时可以独立调整待办磁贴的宽度和高度，文字自动换行；退出编辑后恢复待办操作。

提醒到期时，在鼠标所在屏幕显示透明磨砂全屏提醒和实时时钟，同一批到期事项集中显示，新的到期事项会追加。按 Esc 或「关闭」退出，只关闭提醒，不删除待办；底部不再显示退出说明小字。

主控的待办参数页提供「全屏预览」，使用标明「预览示例」的内容，不修改真实待办及提醒状态。预览期间若有真实提醒到期，真实提醒会替换示例；已有真实提醒时点击预览会聚焦该提醒窗口。

提醒依赖程序运行且待办已开启。退出程序、禁用待办、锁屏、休眠或系统时间跳变期间错过的提醒不补弹；已触发的提醒也不会在重启后重复弹出。事项会继续保留，可看到「已提醒」或「已过期」状态。

### 倒计时

- 在侧边栏启用「倒计时」。默认 240×240 方形磁贴，沿用音乐、天气磁贴的圆角深色背景，支持等比缩放，最小宽度 160 像素。
- 使用鼠标滚轮、上下拖动、点击数字或方向键选择时分秒。上下数字间隔一致，切换时平滑上下移动。最大时长为 24:00:00，选择 24 小时时分、秒归零；零时长不能开始。
- 右上角竖排双点打开预设列表，左上角箭头返回，右上角「＋」新增预设。输入名称和时长后点击「保存」；按钮居中、收窄并上移，底部保留间距。预设保存在本地，支持新增、启动、删除，暂不支持修改。
- 预设列表采用与待办相近的文字和图标尺寸，每行显示名称、时长、启动和删除按钮。点击启动立即计时，同一磁贴只能运行一个倒计时。
- 开始后显示较粗、内径扩大的剩余进度圆环，进度连续平滑变化。每次启动从待办的浅黄、薄荷绿、浅蓝、浅橙、浅粉五种颜色中随机选择，暂停、继续及结束时保持本次颜色；随机选择可能与上次相同。
- 圆环内增加深色衬底，中央显示剩余时分秒；预设名称位于时间上方，加粗并采用本次圆环颜色。名称始终单行，短名称居中，长名称可用鼠标滚轮或横向手势左右滚动查看，不显示滚动条；悬停也可查看完整名称。计时与结束界面在 160 像素尺寸下等比缩放。
- 暂停、继续和取消使用图案按钮，位于圆环下方并留出底部间距；暂停时进度冻结，取消后恢复本次原时长。

到期时直接沿用磁贴背景，分两行显示名称（无预设时为「倒计时」）和「结束」：名称放大加粗并采用本次圆环颜色，「结束」为较小的第二行；长名称保持单行且可平滑横向滚动，不显示滚动条。计时和结束界面的连续滚轮输入累计位移，遵循系统减少动画设置。磁贴自动临时置顶，不弹出全屏页面。结束状态保留到用户点击勾确认，确认后恢复原来的桌面层级，并回到零时长选择界面。待办全屏提醒独立保留，倒计时结束期间仍可触发待办提醒。

休眠和锁屏期间继续计算时长，恢复且解锁后对已到期的倒计时提醒一次。退出程序或关闭、删除磁贴会取消本次计时；重新启动不恢复运行中的倒计时，本地预设仍保留。

### 开机自启

进入左侧「设置」，打开「开机自启」滑块，设置立即生效。登录 Windows 时只显示磁贴和托盘，手动打开程序时显示主控窗口。关闭滑块会移除当前账号的启动项；操作失败时保留原开关状态并显示错误。

页面读取 Windows 实际启动状态。开发测试模式禁用真实启动项修改。

### 天气地点保存

选择省、市、区县后点击「保存地点」，主进程开始解析并保存地址。应用运行期间，切换分类或设置页、最小化及收起到托盘不会取消保存；完全退出程序后的未完成任务不会自动恢复。

保存中的磁贴显示「保存中…」，暂时禁用地区修改、重复提交及删除，其他页面仍可切换。保存完成后更新地址；失败时保留原地址与本次选择，并在主控窗口显示错误，返回天气页可重试。

### QQ 音乐歌词同步

歌词换句和长句滚动依赖 QQ 音乐提供的播放时间。1.0.1 修复了进度时间戳超过 5 秒后停止推进、歌词停在同一句的问题：主进程在进度暂未更新时继续计时，并在收到新进度、暂停、恢复或切歌时重新校准。切换磁贴款式沿用主进程计时。

前台窗口最大化或全屏时，后台提示不能证明音乐磁贴已被完全遮挡。音乐磁贴继续读取播放状态：正常情况下每 400 毫秒轮询，收到后台提示或页面不可见时降为每秒一次；可见长句的滚动只按真实播放与页面可见状态控制，不随全局后台提示停住。该修复同时避免保留旧播放图标和旧歌词。

暂停时停止自动计时；QQ 延迟补发的进度仍可能使歌词位置短暂校正。没有播放时间或匹配歌词时，界面显示相应提示。修改主进程代码后，需要从托盘退出桌屿并重新启动，切换款式不能加载新的主进程代码。

歌词临时降级为纯文本时显示“暂无同步歌词”，不将整首文本拼成一条同步歌词。纯文本缓存保留 30 秒，磁贴按 30 秒间隔重试，每首歌最多请求 3 次（包含首次）；在重试预算内数据源恢复后，可在同一首歌内恢复换句。预算耗尽后不会持续查询，可切歌或退出后重新启动再试。当前保留按行换句与长句滚动，已终止双色逐字歌词方向；短句完整显示，无需横向滚动。

### 天气凭据

天气页可填写自己的和风天气 API Host 和 API KEY；凭据在本机加密保存，不回显 KEY。未配置个人凭据时使用 Open-Meteo 备用源。服务额度和费用以提供方当前规则为准。

## 数据目录与备份

正式程序的数据保存在安装目录的 `data/`：

| 路径 | 内容 |
| --- | --- |
| `data/deskisland.json` | 磁贴、布局、地区、待办内容与排序、提醒状态、倒计时预设与所选时长、显示设置 |
| `data/qweather-user.json` | 加密的个人天气凭据 |
| `data/recordings/` | 待处理音频与异常退出后的录音恢复信息 |
| `data/session/` | Electron 会话与缓存 |
| `data/logs/`、`data/crashes/`、`data/temp/` | 日志、崩溃转储及应用临时文件 |

备份前从托盘退出程序，再复制 `data/`。天气凭据的加密依赖 Windows 账号，跨账号或跨电脑恢复可能需要重新配置。

程序不会在数据目录写入失败时回退到 AppData。Windows 注册表、快捷方式及安装器临时文件仍由系统机制处理；应用无法阻止 Windows 自身生成系统文件。

## 升级与卸载

升级前退出桌屿，再运行新安装器。安装器自动使用之前的安装目录并锁定路径，覆盖程序文件，保留 `data/` 和自启状态。数据格式版本与程序版本独立管理；损坏或不支持的配置会报错并保留原文件。

卸载前退出桌屿。卸载器确认后删除程序、自启项、快捷方式以及 `data/` 中的全部个人数据，**需要保留数据时请先备份**。安装目录内自行存放的其他文件不做整目录递归清除。

## 开发与验证

项目使用 Node.js、Vue、Vite、TypeScript、Electron 及 Windows PowerShell。建议使用 Node.js 24，安装依赖时将缓存放入项目目录：

```powershell
npm ci --cache .tmp/npm-cache
npm run prepare:audio -- "本机 FFmpeg 6.1.1 essentials 的 ffmpeg.exe 路径"
npm test
npm run typecheck
npm run build
.\start-test.cmd
```

开发数据与临时文件放在项目 `.tmp/`，不自动迁移到正式安装。

音频运行时准备命令从 NuGet 获取固定版本 NAudio 2.2.1，并校验 SHA-256；FFmpeg 使用固定 Gyan 6.1.1 essentials 构建并校验 SHA-256。开发依赖放入 `.tmp/audio-runtime/`，打包只复制所需 DLL、编码器与许可文件到 `resources/app/audio-runtime/`，运行时不依赖系统 PATH。原生检查采用可审阅的脚本文件执行，不使用长内联编译命令。

打包使用 `npm run package:win`，要求 Windows x64 和 Inno Setup 7；开发缓存、测试文件与个人数据不会进入安装包。

### 打包

在 Windows x64 环境中安装 Inno Setup，并执行：

```powershell
npm run package:win
```

打包依次运行测试、类型检查和构建，再使用已有 Electron 运行时制作应用目录并编译 Inno 安装器。默认编译器为 `C:\Program Files\Inno Setup 7\ISIDE.exe`，其他位置可通过 `INNO_COMPILER` 环境变量指定 `ISIDE.exe` 或 `ISCC.exe`。

安装包及 SHA-256 文件位于 `dist/`。打包目录只包含运行所需源码、渲染构建、运行时及文档，不包含个人测试数据、凭据、缓存和 `node_modules/`。

## 已知限制

- 音乐控制与歌词匹配受播放器、网络及数据源影响；不保证每首歌曲都有歌词。
- 桌面窗口挂载依赖 Windows 桌面环境，系统或桌面软件变化可能影响显示。
- 当前不提供自动更新；使用新安装器覆盖升级。
- 安装包未进行代码签名，Windows 可能显示安全提示。
- 真实登录自启及首次安装、覆盖安装、卸载结果需要实机验收；编译通过不代表这些验收已完成。

版本变化见 [CHANGELOG](CHANGELOG.md)。提交问题时请提供系统版本、桌屿版本、复现步骤及脱敏后的错误信息，不提供天气 KEY 或个人凭据文件。
